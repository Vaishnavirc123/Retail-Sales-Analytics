
# Retail Sales Analytics Project

## Project Overview
This project focuses on analyzing retail sales data using Python.
It helps understand sales performance, product performance,
category-wise revenue, monthly sales and business profit.

## Objectives
- Analyze retail sales data.
- Clean and organize the dataset.
- Calculate total revenue and profit.
- Identify best-selling products.
- Analyze monthly sales performance.
- Generate reports and visualizations.

## Technologies Used
- Python
- Pandas
- Matplotlib
- CSV Dataset
- PyCharm
